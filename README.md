# Astraya Wallpapers

Live and still wallpapers from [Astraya](https://dynamic-saransh.itch.io/astraya), made
for the Nothing Phone (4a) Pro (1260 × 2800, 9:20). Works on any Android 14+ phone.

**Install:** on the phone, open
https://github.com/Saransh-mittal/astraya-wallpapers/releases/latest/download/astraya-wallpapers.apk
and allow the browser to install it.

**Use:** open *Astraya Wallpapers*.

1. **One tap:** *Set Astraya Mix* → on Android's screen tap **Set** → **Home and lock screens**.
   Every wallpaper in turn on both screens, a new one each time the screen turns off.
2. **Slideshows:** Astraya Mix, Living Story (moving only), Moving home + still lock,
   Paintings (stills only), Nothing edition. One tap each.
3. **Make your own:** the same slideshow on both screens, or a different one for home and
   lock (two system taps: Home screen, then Lock screen). Tick what goes in each and
   choose when it changes (screen off, every 10 minutes, every hour).
4. **One wallpaper:** tap any tile to play or set just that one.

- Live wallpapers play from this app, so keep it installed. Delete the APK file whenever you like.
- Stills stay even if the app is uninstalled.
- Loops pause whenever the wallpaper is out of sight.

The media is built by `output/astraya-wallpapers-nothing-4a-pro/build.sh` in the game
repo; GitHub Actions builds and signs the APK on every push to `main`.
